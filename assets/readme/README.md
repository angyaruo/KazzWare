# README title artwork

The ten PNG feature titles were created for KazzWare using the **built-in image_gen tool** on 2026-10-28. Each is an individual generation with requested true transparency. Original generated pixels and alpha are copied unchanged into this directory. No CLI/API fallback, image editor, remote image hosting or runtime image generation is used.

The visual direction is metallic silver-white lettering, off-black polarized-glass fragments and crimson malware/glitch detail, matching the owner's supplied KazzWare cover. Each title has a feature-specific emblem. The cover at `../kazz-cover.png` is the existing owner-supplied image and is included unchanged at the top of the README.

The exact text, full final prompt and tool choice for every title are saved in [prompts.json](prompts.json). PNG alpha checks confirmed fully transparent and fully opaque pixels in every output. All titles were visually checked for spelling and legibility; HTML image widths and alt text let the README work within GitHub's document layout.

The files are documentation assets, separate from the extension UI and runtime bundles. See [the original art credits](../README.md) for mascot provenance and licensing. No additional redistribution license is granted here.
